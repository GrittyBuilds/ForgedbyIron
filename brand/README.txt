PHYSIQ — BRAND KIT ("Apex" direction)
=====================================

WHAT'S INSIDE
-------------
physiq-brandsheet.html   The brand sheet (open in any browser; fonts are embedded).

svg/
  icon.svg            App icon, full colour, rounded (transparent outside the corners).
  icon-full.svg       App icon, full colour, SQUARE full-bleed (use for app stores).
  icon-mono.svg       Single-colour mark (uses currentColor — set the CSS/fill colour).
  lockup-dark.svg     Icon + wordmark + tagline for dark backgrounds. Text is OUTLINED.
  lockup-light.svg    Icon + wordmark + tagline for light backgrounds. Text outlined.
  wordmark-dark.svg   Wordmark only, on dark. Text outlined (no fonts needed).
  wordmark-light.svg  Wordmark only, on light. Text outlined.

png/
  ios/        AppIcon-*.png  — full-bleed squares (20–1024). Submit the 1024 to the App
              Store; iOS applies the rounded mask, so these are intentionally square.
  android/    ic_launcher-*.png — 48–192 launcher sizes + 512 for the Play Store.
  web/        icon-*.png — rounded, transparent: 512, 192, 180 (apple-touch), 32, 16.

THE MARK
--------
An open progress/activity ring forms the bowl of the "q"; an electric-aqua tail gives it
momentum. Keep the ring OPEN — the gap is the identity and keeps it from reading like a
search loupe. Don't recolour the ring or add a second accent.

COLOURS
-------
Ink        #0A0A0B      Graphite   #14161B      Panel     #1B1E24
Bone       #EEF1F4      Steel      #9AA1AB      Slate     #6B7280
Aqua       #2FE3C7      Aqua Deep  #12B9A0  (accent on light backgrounds)

Aqua is the single accent — ring tail, active states, key metrics, primary buttons.
Use it sparingly, never as a large fill. Bone is the logo/text on dark; ink (#14161B) on light.

TYPE (both free, SIL Open Font License)
---------------------------------------
Display / headings   Space Grotesk (Bold 700)
Wordmark             Space Grotesk (Medium 500, lowercase, accent q)
Tagline              Space Grotesk (Regular 400, tracked +0.3em)
Body & UI            Inter

The lockup and wordmark SVGs have the type converted to outlines, so they render anywhere
without the fonts installed. For live app UI, load Space Grotesk + Inter from Google Fonts
or @fontsource.

USAGE
-----
Do:  keep clear space; keep the ring gap open; bone/aqua on dark, ink/aqua-deep on light;
     aqua as the only accent, used sparingly.
Don't: close the ring, recolour it, add a second accent, skew/stretch, or shadow the wordmark.
